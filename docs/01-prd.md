请基于 js-audio-recorder 和 media-devices 两个库，封装一个通用浏览器录音工具类，项目名称 audio-recorder，要求：

1. 职责边界：工具只负责麦克风检测、录音控制、输出音频数据和波形信息，**不包含任何UI、Canvas绘制逻辑，不绑定任何业务场景**；上层拿到波形数据后自行实现渲染。
2. 基础能力：
- 麦克风设备检测、浏览器支持检测、权限预检
- 录音：开始 / 暂停 / 继续 / 停止
- 录音时长计时回调，支持设置最大录音时长，超时自动停止录音
- 停止录音后返回 wav Blob、audioUrl、录音时长
3. 波形数据输出：
- 通过回调向外输出实时波形信息：音量vol(0~100)、时域波形Uint8Array数组（1024点，值域0~255）、当前录音时长
- 录音进行中波形数组实时更新；暂停/停止不再刷新波形数据
4. 资源管理：提供destroy方法，释放麦克风、清除定时器，防止资源泄漏
5. 异常处理：捕获麦克风无设备、权限拒绝、浏览器不支持等错误
6. 架构原则：
- 工具类保持通用，不要内置绘制代码
- 所有UI相关、波形渲染逻辑全部交给上层回调实现
- 异步操作全部使用Promise
- 支持传入回调函数：onTimeUpdate、onWaveDataUpdate、onMaxReach
7. 输出：完整ES Module class代码，附带使用示例，不要引入框架（Vue/React）依赖，原生JS可用
